# forkip-web

The public web presence for forkip-web: a home page and twelve content routes rendered with Next.js App Router.

## Language

**Responsive tier**:
One of the screen bands the site is designed for: base below 640px, sm from 640px, md from 768px, lg from 1024px, and xl from 1280px.
_Avoid_: breakpoint size, screen class

**Responsive pass**:
A deliberate review of a page or component at every **Responsive tier** to make the existing design fit cleanly, without changing branding, copy or color.
_Avoid_: redesign, rework

**Site content**:
Public prose and structured records shown on the site, excluding code, config and UI labels.
_Avoid_: copy, data
